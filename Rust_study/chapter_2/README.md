# Chapter 2. 출력, 문자열, 참조 및 소유권 기초

본 챕터에서는 러스트의 다양한 출력 방식, 문자열 타입, 상수의 종류, 참조와 소유권의 기초 개념에 대해 학습했습니다.

## 📝 주요 학습 내용

### 1. 출력의 종류 (`print!` vs `println!`)
- `print!()`: 줄바꿈 없이 출력합니다.
- `println!()`: 출력 후 줄바꿈(새 줄)을 수행합니다.

### 2. Raw String (`r#`)
- `r#"..."#`: 문자열 내부의 이스케이프 문자(예: `\"`)를 처리하지 않고 작성한 그대로(Raw) 출력합니다. 가독성을 높일 때 유용합니다.
- **예약어 사용**: `let`, `return` 같은 러스트의 예약어를 변수나 함수 이름으로 꼭 사용해야 할 때 앞에 `r#`을 붙이면 사용할 수 있습니다. (예: `let r#let = 10;`, `fn r#return() { ... }`)

### 3. 출력 포맷팅 (Formatting)
`println!` 등에서 `{}` 안에 값을 넣어 순서를 지정할 수 있습니다.
- **인덱스 기반**: `{1} + {0} = {2}`처럼 숫자를 넣어 인자의 순서를 바꿀 수 있습니다.
- **이름(변수명) 기반**: `{b} + {a} = {c}`처럼 이름(키워드)을 지정해 매핑할 수 있습니다. (예: `a=1, b=2`)

### 4. 문자열 타입 (`&str` vs `String`)
- `&str`: 간단하고 고정된 문자열 슬라이스로, 속도가 빠릅니다.
- `String::from("...")`: 힙(Heap) 메모리에 할당되어 길이가 변할 수 있는 복잡한 문자열 타입입니다. 다양한 메서드를 제공하지만 비교적 무겁습니다.

### 5. `const` 와 `static`
- `const`: **상수**로, 컴파일 타임(Compile time)에 값이 결정되며 코드 내에서 값 자체가 대체됩니다.
- `static`: **전역 변수**로, 런타임(Runtime)에 사용되며 메모리 상의 고정된 위치를 가집니다.

### 6. 참조 (Reference) 와 가변 참조
- `&`: 데이터의 소유권을 가져오지 않고 값만 읽을 수 있도록 참조합니다. (예: `let country_ref = &country;`)
- `&mut`: 값을 변경할 수 있는 가변 참조입니다. 원본 변수도 `mut`로 선언되어야 합니다.

### 7. 섀도잉 (Shadowing)과 참조
새로운 `let`으로 기존 변수와 같은 이름의 변수를 선언(섀도잉)해도, 기존 변수의 메모리는 즉시 파괴되는 것이 아니라 스코프가 끝날 때까지 유지됩니다. 따라서 이전에 참조를 만들어 두었다면 그 참조는 여전히 기존 값을 가리킵니다.

### 8. 함수와 소유권 (Ownership) 기초
- 값을 함수에 그대로 전달하면(예: `String`) **소유권이 이동(Move)**되어 원래 변수를 더 이상 사용할 수 없게 됩니다.
- 값 대신 참조(`&`)를 넘겨주면 소유권을 주지 않고 잠시 **빌려주는(Borrowing)** 것이므로, 함수 호출 후에도 원래 변수를 계속 사용할 수 있습니다.

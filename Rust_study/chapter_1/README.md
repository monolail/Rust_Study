# Chapter 1. 러스트 기본 문법 (Primitive types, Variables, Functions)

본 챕터에서는 러스트(Rust)의 가장 기본적인 문법과 데이터 타입에 대해 학습했습니다.

## 📝 주요 학습 내용

### 1. 주석 (Comments)
- `//`: 한 줄 주석
- `/* ... */`: 여러 줄(블록) 주석
- 문서화 주석(Documentation comments) 등 지원

### 2. 원시 타입 (Primitive Types)
- **정수형 (Integer Types)**
  - 부호 있는 정수(Signed): `i8`, `i16`, `i32`, `i64`, `i128`, `isize`
  - 부호 없는 정수(Unsigned): `u8`, `u16`, `u32`, `u64`, `u128`, `usize`
  - `isize`와 `usize`는 실행 환경(32bit/64bit 운영체제)에 따라 크기가 자동으로 결정됩니다.
  - 타입별 최댓값/최솟값을 구할 수 있습니다. (예: `std::i32::MAX`)
- **실수형 (Floating-Point Types)**
  - `f32`, `f64` (러스트는 기본적으로 `f64`를 추론합니다.)

### 3. 타입 변환 (Type Casting)
- `as` 키워드를 사용하여 변수 간의 명시적 타입 변환이 가능합니다. (예: `my_number as u32`)

### 4. 문자열 길이 확인
- `.len()`: 문자열의 **바이트 수**를 반환합니다. (한글 등 유니코드 문자가 섞인 경우 실제 글자 수와 다를 수 있습니다.)
- `.chars().count()`: 실제 **글자(Character) 개수**를 반환합니다.

### 5. 타입 추론 및 숫자 표기법
- 러스트는 값을 기반으로 타입을 똑똑하게 추론합니다. (예: `let number = 42;` -> `i32`)
- 값 뒤에 타입을 접미사로 붙이거나 가독성을 위해 언더바(`_`)를 섞어 쓸 수 있습니다. (예: `42u32`, `42_u32`)

### 6. 출력문 (`println!`)
- `{}` 안에 값을 넣어 포맷팅 출력합니다.
- 최신 러스트에서는 중괄호 안에 직접 변수명을 넣을 수도 있습니다. (예: `println!("The value is: {my_variable}");`)

### 7. 변수와 섀도잉 (Variables & Shadowing)
- `let`으로 선언된 변수는 기본적으로 **불변(Immutable)**이라 값이 변경되지 않습니다.
- **섀도잉(Shadowing)**: 이미 선언된 동일한 이름의 변수를 다시 `let`으로 재선언하면 이전 값을 덮어씁니다. 이는 주로 값의 형태나 타입을 변환해 재할당할 때 씁니다.

### 8. 함수 (Functions)
- 함수의 반환값 타입은 `-> Type` 형태로 명시합니다.
- 함수의 가장 마지막에 위치한 표현식(세미콜론 `;` 없이 끝나는 줄)은 자동으로 반환(return)됩니다.

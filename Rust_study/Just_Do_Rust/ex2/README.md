# ex2: 커맨드라인 인자(CLI Arguments) 처리

## 1. 개요
`std::env` 표준 라이브러리를 사용하여 프로그램 실행 시 전달되는 커맨드라인 인자를 읽고 처리하는 실습입니다.

## 2. 주요 학습 내용
- 표준 라이브러리 모듈 사용: `use std::env;`로 커맨드라인 환경 관련 모듈을 가져옵니다.
- 실행 인자 수집: `env::args().collect()`를 사용하여 커맨드라인 인자들을 `Vec<String>` 형태로 수집합니다.
- 벡터 인덱싱 및 참조: 수집된 벡터 인덱스를 참조(`&args[1]`, `&args[2]`)하여 전달받은 인자값을 다룹니다.

## 3. 실행 방법
```bash
cargo run -- <source_file> <target_file>
```

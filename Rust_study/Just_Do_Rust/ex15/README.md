# ex15: 소유권(Ownership)과 참조/대여(Borrowing)

## 1. 개요
Rust의 핵심 개념인 소유권 이동(Move), 불변 대여(`&`), 가변 대여(`&mut`), 그리고 참조 타입 간의 Copy/Move 차이를 학습하는 실습입니다.

## 2. 주요 학습 내용
- 소유권 이동 (Move): 변수 할당 및 함수 인자 전달 시 힙 메모리 소유권이 이전되어 이전 변수는 사용할 수 없게 됩니다.
- 불변 참조 (`&`): 소유권을 넘기지 않고 읽기 권한만 대여합니다. 불변 참조(`&T`)는 `Copy` 트레이트를 구현하므로 복사됩니다.
- 가변 참조 (`&mut`): 데이터 수정 권한을 대여하며, 원본 데이터를 직접 수정할 수 있습니다. 가변 참조(`&mut T`)는 `Copy`가 아니므로 재할당 시 소유권이 이동(Move)합니다.

## 3. 실행 방법
```bash
cargo run
```

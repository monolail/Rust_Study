# ex11: 이터레이터(Iterator) 기본과 변환(map, collect)

## 1. 개요
Rust의 이터레이터 종류(`iter`, `into_iter`, `iter_mut`), 요소 순회 및 변환 메서드(`map`, `for_each`), 그리고 다양한 컬렉션(`Vec`, `HashMap`, `HashSet`)으로의 수집(`collect`)을 학습하는 실습입니다.

## 2. 주요 학습 내용
- 이터레이터 종류:
  - `iter()`: 요소를 불변 참조(`&T`)로 순회합니다.
  - `into_iter()`: 컬렉션의 소유권을 가져와 값 자체(`T`)로 순회합니다.
  - `iter_mut()`: 가변 참조(`&mut T`)로 순회하여 원본 컬렉션의 요소를 직접 수정합니다.
- 변환과 수집:
  - `map()`: 클로저를 적용하여 각 요소를 변환합니다.
  - `collect()`: 변환된 이터레이터를 벡터, 해시맵(`HashMap`), 해시셋(`HashSet`) 등 지정된 컬렉션 타입으로 수집합니다.
- 실습 응용: 문자열 소문자 변환, 문자 출현 빈도수 해시맵 생성, 알파벳 집합 추출.

## 3. 실행 방법
```bash
cargo run
```

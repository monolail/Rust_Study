# ex14: 문자열 슬라이싱, 변환 및 필터링

## 1. 개요
문자열 슬라이스와 이터레이터 어댑터(`take`, `filter_map`, `filter`)를 활용하여 문자열에서 원하는 부분의 숫자를 추출하고 가공하는 실습입니다.

## 2. 주요 학습 내용
- `take(n)`: 문자 이터레이터의 앞 n개 요소를 가져옵니다.
- 문자열 슬라이스: 바이트 범위 인덱싱(`input[4..9]`)을 통해 특정 부분 문자열을 슬라이스합니다.
- 숫자 변환 및 필터링: `to_digit(10)`을 `filter_map`과 연계하여 문자를 숫자로 변환하고, 조건 필터링 후 합계(`sum`)를 산출합니다.

cargo test -- --nocapture

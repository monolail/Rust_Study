# ex10: 문자열(String, &str) 다루기

## 1. 개요
문자열 슬라이스(`&str`)와 소유권을 가진 힙 할당 문자열(`String`)의 차이, 바이트 수와 문자 수의 차이, 문자열 탐색 및 연결 방법을 학습하는 실습입니다.

## 2. 주요 학습 내용
- 길이 측정: `len()`은 바이트 수를 반환하며(UTF-8 한글의 경우 문자당 3바이트), 실제 글자 수는 `chars().count()`를 통해 계산합니다.
- 문자열 탐색: `contains()` 메서드를 사용하여 특정 부분 문자열의 포함 여부를 확인합니다.
- String 생성 및 변환: `String::from()`, `to_owned()`, `to_string()`을 통해 문자열 슬라이스를 `String`으로 변환합니다.
- 문자열 결합: `push_str()` 메서드로 문자열을 덧붙이거나 `+` 연산자(`String + &str`)를 통해 문자열을 연결합니다.

## 3. 실행 방법
```bash
cargo run
```

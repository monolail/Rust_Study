# ex12: 이터레이터 필터링(filter)과 참조 패턴

## 1. 개요
이터레이터의 `filter()` 메서드를 사용하여 특정 조건을 만족하는 요소만 추출하는 방법과 참조의 참조(`&&T`)를 다루는 패턴을 학습하는 실습입니다.

## 2. 주요 학습 내용
- `filter()` 메서드: 클로저가 `true`를 반환하는 요소만 남기는 이터레이터 어댑터입니다.
- 이중 참조(`&&T`) 다루기:
  - `v.iter()`가 참조를 생성하고 `filter`는 해당 요소의 참조를 인자로 넘기기 때문에 `&&T` 형태가 됩니다.
  - 패턴 매칭 문법(`|&&x|`)을 통해 값을 바로 바인딩하거나, 역참조 연산자(`|x| *x`)를 사용하여 조건식을 작성할 수 있습니다.
- 단위 테스트: `#[test]` 어노테이션을 활용한 테스트 함수 작성 및 실행 방법을 실습합니다.

## 3. 실행 방법
```bash
cargo test -- --nocapture
```

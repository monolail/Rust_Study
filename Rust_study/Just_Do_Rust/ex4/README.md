# ex4: 튜플, 배열, 슬라이스 및 벡터

## 1. 개요
Rust의 복합 데이터 타입인 튜플(Tuple), 고정 길이 배열(Array), 슬라이스(Slice), 그리고 가변 길이 컬렉션인 벡터(Vector)의 기본 사용법을 학습하는 실습입니다.

## 2. 주요 학습 내용
- 튜플 (Tuple): 서로 다른 타입의 값을 묶어 다루며, 인덱스(`.0`, `.1`)로 접근하거나 함수의 다중 반환값으로 활용합니다.
- 배열 (Array): 고정된 길이와 동일한 타입을 가지며, 인덱스 접근 및 초기화 문법(`[초기값; 길이]`)을 사용합니다.
- 슬라이스 (Slice): 배열의 일부 연속된 요소를 참조(`&a[1..]`, `&a[..]`)하여 전달 및 출력합니다.
- 벡터 (Vector): `vec!` 매크로를 사용하여 동적 크기의 컬렉션을 생성하고, `insert()` 메서드로 요소를 삽입합니다.

## 3. 실행 방법
```bash
cargo run
```

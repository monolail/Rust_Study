# ex8: 벡터(Vector) 심화 및 컬렉션 제어

## 1. 개요
동적 배열인 `Vec<T>`의 다양한 생성 방식, 안전한 원소 접근(`get`), 순회 방식에 따른 소유권 차이, 그리고 벡터 조작 메서드를 학습하는 실습입니다.

## 2. 주요 학습 내용
- 벡터 생성: `Vec::new()`, `vec![]` 매크로 및 배열의 `to_vec()` 메서드를 활용합니다.
- 안전한 원소 접근: 인덱스 직접 참조(`v[i]`) 외에 패닉을 방지하는 `v.get(i)` 메서드와 `if let Some` 패턴 매칭을 실습합니다.
- 순회 및 소유권:
  - `&v`: 불변 참조를 통한 읽기 순회.
  - `&mut v`: 가변 참조를 통해 원소 값을 직접 수정하는 순회.
  - `v`: 소유권 이동(Move)이 발생하여 순회 이후 기존 벡터를 재사용할 수 없습니다.
- 주요 조작 메서드: `append` (벡터 병합), `resize` (크기 재조정), `fill` (값 채우기), `truncate` (크기 축소).

## 3. 실행 방법
```bash
cargo run
```

# ex1: 반복문과 가변 변수를 활용한 합계 계산

## 1. 개요
1부터 N까지의 정수 합을 계산하는 실습입니다.

## 2. 주요 학습 내용
- 가변 변수 선언: `let mut`을 사용하여 값을 변경할 수 있는 변수를 선언합니다.
- 범위 문법: `1..=n` 구문을 사용하여 1부터 n까지를 포함하는 범위를 생성합니다.
- for 반복문: 범위를 순회하며 누적 합계를 계산합니다.
- 함수 정의 및 반환: 매개변수와 반환값의 타입을 지정하고 `return` 키워드를 통해 결과를 반환합니다.

## 3. 실행 방법
```bash
cargo run
```

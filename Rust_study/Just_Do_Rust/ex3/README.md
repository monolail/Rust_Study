# ex3: 변수, 상수(const) 및 스코프

## 1. 개요
변수의 가변성(mut), 미초기화 변수 선언, 전역 및 로컬 상수(const)의 정의와 함수 스코프에 대해 학습하는 실습입니다.

## 2. 주요 학습 내용
- 상수 선언: `const` 키워드를 사용하여 전역 및 함수 내부에 상수를 선언합니다. 타입 명시가 필수적입니다.
- 가변 변수와 불변 변수: `let mut`과 `let`을 사용한 변수 정의 및 초기화 방식의 차이를 확인합니다.
- 함수와 전역 스코프: 전역으로 선언된 상수는 다른 함수(`sub`)에서도 접근하여 사용할 수 있습니다.

## 3. 실행 방법
```bash
cargo run
```

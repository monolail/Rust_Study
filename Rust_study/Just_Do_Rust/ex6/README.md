# ex6: 제어 흐름과 패턴 매칭 (if, match, if let, let-else)

## 1. 개요
조건문(if-else), 표현식으로서의 if, match 문을 통한 패턴 매칭, 그리고 if let 및 let-else 구문의 사용법을 학습하는 실습입니다.

## 2. 주요 학습 내용
- if 표현식: 조건에 따라 분기하며, 결과를 변수에 직접 할당할 수 있습니다.
- match 패턴 매칭: 단일 값 매칭, 와일드카드(`_`), 범위 매칭(`0..=10`), 튜플 매칭을 처리합니다.
- if let 구문: 특정 패턴(예: `Some`)에 대해서만 간결하게 처리합니다.
- let-else 구문: 패턴 불일치 시 조기 리턴(early return)을 수행하여 가독성을 높입니다.

## 3. 실행 방법
```bash
cargo run
```

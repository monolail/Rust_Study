# ex16: 컬렉션 복제, 순회 및 해시맵 필터링

## 1. 개요
벡터의 `clone()`과 `into_iter()` 조합, 가변 참조를 통한 벡터 원소 수정, 그리고 `HashMap` 참조를 인자로 받아 조건에 맞는 키를 필터링하는 함수 작성을 학습하는 실습입니다.

## 2. 주요 학습 내용
- `clone()`과 `into_iter()`: 원본 벡터를 유지하면서 복제본의 소유권을 소비하는 이터레이터를 생성합니다.
- 가변 순회: `for i in &mut v` 구문으로 각 원소에 대한 역참조 연산(`*i += 10`)을 수행하여 값을 변경합니다.
- 해시맵 함수 처리: `&HashMap` 참조를 전달받아 소유권 이동 없이 안전하게 순회하며, 조건(`> limit`)에 맞는 키를 새 벡터로 수집하여 반환합니다.

## 3. 실행 방법
```bash
cargo run
```

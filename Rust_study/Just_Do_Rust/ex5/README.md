# ex5: 구조체(Struct), 메서드 및 클로저(Closure)

## 1. 개요
구조체 정의와 구현 블록(impl)을 통한 연관 함수 및 메서드 작성법, 그리고 클로저와 bool 조건 메서드 활용법을 학습하는 실습입니다.

## 2. 주요 학습 내용
- 구조체 정의: 필드를 가진 사용자 정의 데이터 타입(`Point`)을 선언합니다.
- 연관 함수와 메서드:
  - 연관 함수: `self`를 받지 않고 타입 네임스페이스로 호출하는 생성자 함수(`Point::new`)를 정의합니다.
  - 메서드: 첫 번째 매개변수로 `&self`를 받아 인스턴스 데이터를 다루는 메서드(`distance`)를 정의합니다.
- 테스트/검증: `assert_eq!` 매크로를 활용하여 결과값을 검증합니다.
- 클로저: `|x| x + 1` 형태의 익명 함수를 정의하고 호출합니다.
- `bool` 편의 메서드: `then(|| ...)`, `then_some(...)`을 활용하여 조건부로 `Option` 값을 반환하는 방식을 실습합니다.

## 3. 실행 방법
```bash
cargo run
```

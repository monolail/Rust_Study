# ex7: 다양한 반복문 (for, loop, while let)

## 1. 개요
Rust에서 제공하는 여러 형태의 반복문(for, loop, while let)과 반복 제어(break)의 사용법을 학습하는 실습입니다.

## 2. 주요 학습 내용
- for 루프: 범위(`1..=100`)를 순회하며 누적 연산을 수행하고, 조건 만족 시 `break`로 탈출합니다.
- loop 문: 무한 반복을 수행하며 조건에 따른 `break`를 통해 반복을 제어합니다. 중첩 루프 구성도 가능합니다.
- while let 구문: `Option` 값을 반환하는 메서드(예: `Vec::pop()`)와 연계하여 값이 존재하는 동안 반복을 실행합니다.

## 3. 실행 방법
```bash
cargo run
```

## 💻 러스트 터미널 실행 방법
1. **단일 파일 컴파일 및 실행 (`rustc`)**
   ```bash
   rustc main.rs    # 컴파일 (실행 파일 생성)
   ./main           # 실행 (Windows의 경우 .\main.exe)
   ```
2. **카고(Cargo) 프로젝트 사용 시**
   ```bash
   cargo build      # 프로젝트 빌드
   cargo run        # 빌드 및 실행
   cargo check      # 에러 없이 컴파일되는지 문법 등만 빠르게 확인
   ```
